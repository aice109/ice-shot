# 截图带壳

截图后给成品图加一层 **macOS 窗口壳**：窗口标题栏、红黄绿交通灯、可选标题、圆角、描边、投影，以及可选的背景与留白。

本文是设计与开发切片文档。实现进度按「最小可交付单元」推进，每一步都可单独验收。

> **进度（2026-10-26）**：M1–M4 已全部完成。popover 预览、全部样式选项、
> 复制 / 保存 / 贴图、跨次记住样式都已就位，历史库仍只存原图。
> 实现细节见 [screenshot-frame-todo.md](screenshot-frame-todo.md)。

## 一、结论

做 macOS 窗口壳，不做手机壳、假菜单栏、假 Dock、桌面壁纸背景。

原因：

- 这是 macOS 应用，窗口是最容易识别、最不抢内容的本机视觉语言。
- 矢量绘制，不依赖系统版本截图，也不需要新增截屏权限。
- 历史库继续保存原图；带壳只影响复制 / 保存 / 贴图，是**输出设置**，不是标注，也不进撤销栈。

两种样式：

| 样式 | 内容 | 用在哪 |
| --- | --- | --- |
| 窗口 | 标题栏 + 红黄绿 + 可选标题 + 圆角 + 投影 | 区域 / 全屏 / 全部显示器 / 长截图 |
| 仅阴影 | 圆角 + 描边 + 投影 + 背景，不加重标题栏 | 窗口截图（**唯一选项**）、整屏截图 |
| MacBook | 机身 + 黑边 + 刘海 | 全屏 / 全部显示器（顶替「窗口」档） |

`Chrome` 的可用档位由来源决定，见 `ScreenshotFrameStyle.allowedChrome(for:)`；
`.macbook` 的实际渲染转交 `DeviceFrameComposer`（详见 [screenshot-device-frame.md](screenshot-device-frame.md)）。

窗口截图不给选择：它的画面里已经带着自己的红黄绿，再套一层窗口壳就是双层交通灯。
这条约束由 `ScreenshotFrameStyle.allowedChrome(for:)` 单点给出，
`EditorModel` 在写入口做归一，所以 popover / `⌘B` / 偏好记忆都绕不过去。

## 二、视觉规格

以内容宽度 1000 px 为 1 单位：

```text
u = clamp(内容宽 / 1000, 0.8, 2.0)
```

所有几何值乘 `u`。

```text
┌──────────────────────────────────────┐  ← 外圆角 12u + 1u 描边
│  ●   ●   ●             标题           │  ← 标题栏 28u
├──────────────────────────────────────┤  ← 0.5u 分隔线
│                                      │
│              截图内容                 │
│                                      │
└──────────────────────────────────────┘
        ↕ 外边距 + 柔和投影 + 可选背景
```

| 项目 | 规格 |
| --- | --- |
| 标题栏高度 | 28u |
| 窗口圆角 | 12u |
| 交通灯直径 | 12u |
| 交通灯间距 | 8u |
| 交通灯左边距 | 20u |
| 标题字号 | 13u，居中，secondary 色 |
| 标题栏分隔线 | 0.5u |
| 外描边 | 1u |
| 投影 | 模糊 40u、向下 16u、透明度约 0.28 |
| 外边距 | 小 32u / 中 64u / 大 96u |

固定内容色（不跟随 App 外观，保证导出结果稳定）：

| 部位 | 浅色 | 深色 |
| --- | --- | --- |
| 标题栏 | `#FAFAFA` → `#F0F0F0` | `#303032` → `#252527` |
| 窗体 | `#FFFFFF` | `#1C1C1E` |
| 分隔线 | `#00000014` | `#FFFFFF1A` |
| 外描边 | `#00000014` | `#FFFFFF1A` |
| 标题 | `#3C3C43` 60% | `#FFFFFF` 60% |

交通灯：

| 按钮 | 填充 | 描边 |
| --- | --- | --- |
| 红 | `#FF5F57` | `#E0443E` |
| 黄 | `#FEBC2E` | `#DEA123` |
| 绿 | `#28C840` | `#1AAB29` |

外观三档：自动 / 浅色 / 深色。自动模式采样截图顶部一条的平均亮度决定，不读系统设置。

背景：透明 + 石墨 / 海蓝 / 晨曦 / 极光四组内置渐变。全部本地固定色，不读桌面壁纸，不联网。

## 三、交互

入口在截图浮层与编辑器共用的输出胶囊里，图标 `macwindow`，放在复制 / 保存之前。开启时高亮。

点击弹出原生 popover：

- 带壳开关
- 实时预览（降采样合成）
- 样式：窗口 / 仅阴影（窗口截图只有「仅阴影」，不显示选择器，只说明原因）
- 外观：自动 / 浅色 / 深色
- 背景：透明 + 四组渐变
- 边距：小 / 中 / 大
- 标题：可选输入框，默认空
- 阴影：开 / 关

规则：

- 首次使用时带壳关闭；之后按上次状态恢复（上次开着就仍开着）。
- 点击按钮时按上次样式直接开启并弹出预览，弹窗里可以关掉。
- 历史库始终保存原图。
- 带壳只影响复制 / 保存 / 贴图。
- 标题不自动填窗口标题，避免把隐私信息带进导出图。
- 窗口来源的截图只能用「仅阴影」：不是默认值，而是硬约束（见上）。
- `⌘B` 快速开关（编辑器窗口与截图浮层都支持）。

第一版不改造主画布：浮层的选区、边框、手柄坐标都绑定原图，把壳画到选区外会和现有交互打架。统一用 popover 里的预览。编辑器窗口是否需要更大的画布预览，放到后续评估。

## 四、技术

### Core

- `ScreenshotFrameStyle`：样式、外观、背景、边距、阴影、标题。
- `ScreenshotFrameComposer`：纯 CoreGraphics 渲染器，输入 `CGImage + style`，输出带壳 `CGImage`。
- `ScreenshotFramePalette`：固定内容色与渐变。
- `ScreenshotFramePreferences`：`UserDefaults` 记住上次开关状态与样式（两字段独立）。

### 关键约束

1. **先裁剪，后套壳。** 浮层输出已经是「渲染标注 → 按选区裁剪」，壳必须加在裁剪之后。
2. `EditorModel.renderedImage()` 继续只返回内容图，不把壳烘进模型。
3. 浮层和编辑器共用同一个合成入口，避免两处行为漂移。
4. 浮层预览需要拿到裁好的选区内容，通过闭包注入工具栏。
5. 全部显示器批量保存时，`SelectionFinish` 带上 `frameStyle`，逐张套同一个壳；复制 / 贴图仍只处理当前屏。
6. 不新增权限、不联网、不改 SwiftData 模型 / schema。
7. 预览用降采样内容；导出用全分辨率。

## 五、开发切片

每一步都以 `Scripts/gate.sh` 通过为前提，验收后再提交。

### M1 · 窗口壳渲染器 + 预览 ✅

- 新增 Core 样式、调色板、渲染器。
- 工具栏新增「带壳」按钮。
- popover 里可以开关带壳，并看到窗口壳预览。
- 此步骤只做预览，复制 / 保存 / 贴图尚未接入。
- 单测覆盖尺寸、透明底、渐变底、明暗、交通灯、投影、预览缩放。

验收：截图后打开浮层 → 点「带壳」→ 开关打开 → popover 里出现带标题栏、交通灯、投影的窗口壳。

### M2 · 输出接入 ✅

- 复制 / 保存 / 贴图使用带壳后的图。
- 关闭后输出与原图逐像素一致。
- 浮层先裁剪再套壳；历史原图不变。
- 全部显示器批量保存套同一个壳。
- 工具栏高亮态与状态提示。

实现细节：统一出口是 `ScreenshotFrameComposer.compose(_:cropRect:style:)`，
编辑器侧再包一层 `EditorModel.exportImage()`；`renderedImage()` 仍然不带壳。

验收：开启带壳后复制 / 保存 / 贴图，得到带壳图；关闭后得到原图。

### M3 · 样式选项 ✅

- 外观、背景、边距、标题、阴影。
- 仅阴影样式。
- 窗口来源**锁定**仅阴影（不是默认值，是不可选）。

实现：全部控件写回 `EditorModel.setFrameStyle`，靠 `task(id: model.frameStyle)`
重绘预览；窗口来源经 `SelectionOverlayController.present(source:)` →
`Session.source` → `EditorModel.applyDefaultFrameStyle(for:)`，
再由 `setFrameStyle` 在写入口归一，保证约束绕不过去。

验收：逐项切换，popover 预览与最终输出一致。

### M4 · 完整收尾 ✅

- 偏好记忆：`ScreenshotFramePreferences` 逐字段存原始值；
  同时记住**开关**与**样式**，上次开着就仍开着、没开过就关着。
- 全部显示器批量保存套壳（M2 已完成）。
- 中英文案、路线图与本文档。
- `⌘B` 快速开关（编辑器窗口 + 截图浮层）。
- 最终门禁绿灯。
