# 路线图

IceShot 的功能全貌与后续规划。已完成的能力同样列在这里，方便对照「现在能做什么、后面还要做什么」。

**不变的底线**：本地处理、只在用户主动触发时截取、不静默上传。

**状态标记**

| 标记 | 含义 |
| --- | --- |
| ✅ | 已完成 |
| 🔜 | 计划中，尚未开始 |
| ❌ | 已取消，不做（保留记录以免重复讨论） |

---

## ✅ 已完成

### 截取

| 状态 | 能力 | 说明 |
| --- | --- | --- |
| ✅ | 区域截图 | 拖拽 / 反向拖拽框选、实时尺寸、8× 像素放大镜、方向键微调、`⇧` 锁比例、`⌥` 中心缩放、Space 拖动、双击确认 |
| ✅ | 点窗口即截 | 未框选时悬停高亮光标下窗口，点击截该窗口、拖拽仍是框选；浮动窗口 / 贴图 / 桌面 / 菜单栏可选；所见即所得 |
| ✅ | 窗口截图 | 独立入口，悬停高亮、自动去阴影、多显示器、可取被遮挡内容 |
| ✅ | 全屏截图 | 当前显示器，或逐屏截取全部显示器 |
| ✅ | 延时截图 | 3 / 5 / 10 秒倒计时，可取消 |
| ✅ | 重复上次区域 | 复用上次选区，显示环境变化时自动回退 |
| ✅ | 滚动长截图 | 手动滚动 + 自动拼接，重叠带上下双向匹配，1:1 像素不缩放 |
| ✅ | 空白帧拦截 | 不透明像素占比过低判为无可截内容 |

### 标注

| 状态 | 能力 | 说明 |
| --- | --- | --- |
| ✅ | 基础工具 | 矩形、椭圆、直线、箭头、画笔、高亮、文字、马赛克、序号 |
| ✅ | 增强工具 | 聚光灯（区域外压暗）、放大镜（框内显示放大内容） |
| ✅ | 文字背景 | 无 / 实底 / 半透，底色取标注色、文字自动对比色，输入所见即所得 |
| ✅ | 马赛克质感 | 马赛克 / 模糊 / 噪点 / 纯色 |
| ✅ | 二级选项 | 参数不常驻，点工具弹出该项自己的浮窗；粗细全工具共用一份 |
| ✅ | 内置色板 | 8 色圆形色块，设置「标注」页可改（2–8 色、可恢复默认） |
| ✅ | 选中调参 | 文字 / 马赛克 / 聚光灯 / 放大镜选中后可直接改参数并撤销 |
| ✅ | 编辑操作 | 选择移动、撤销 / 重做、复制、另存为 PNG |
| ✅ | 裁剪 | 编辑器内拉框 / 8 手柄 / 平移，图像与标注同步映射，一步撤销 |
| ✅ | 旋转 / 翻转 | 90° 顺逆时针与镜像，标注逐点映射，文字保持正立 |
| ✅ | 操作条 | 浮层与编辑器共用同一条玻璃操作条，最透玻璃下仍可读 |
| ✅ | 光标提示 | 所有可拖动 / 可缩放位置都有对应光标 |
| ❌ | 自动打码 / 头像昵称识别 | 试做后取消：系统 Vision 没有版式语义，样本模板匹配在真实聊天截图上漏检与误配都明显。重做前要先能可靠认出应用版式 |
| ❌ | 标注预设 | 试做后取消：真机试用下来帮助有限，颜色与粗细本来就在操作条上一两步能改。重做前要先有真正高频的「多参数组合」场景 |

## ❌ 明确不做

| 状态 | 事项 | 说明 |

| ❌ | 账号 / 云同步 / 分享链接 / 团队协作 | 定位是本机工具，不做多人协作与云端存储 |
